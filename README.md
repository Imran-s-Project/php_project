# Exam Website — PHP + MySQL + Python

একটি সম্পূর্ণ ফাংশনাল অনলাইন এক্সাম সিস্টেম। PHP + MySQL দিয়ে তৈরি মূল ওয়েবসাইট (শিক্ষার্থী পোর্টাল + অ্যাডমিন প্যানেল), এবং Excel/CSV থেকে বাল্ক প্রশ্ন ইম্পোর্টের জন্য একটি Python স্ক্রিপ্ট।

## ফিচার

**শিক্ষার্থীদের জন্য**
- রেজিস্ট্রেশন ও লগইন
- টাইমার সহ MCQ পরীক্ষা (সময় শেষ হলে অটো-সাবমিট)
- তাৎক্ষণিক ফলাফল: স্কোর, পাস/ফেইল, প্রতিটি প্রশ্নে সঠিক/ভুল উত্তর ও ব্যাখ্যা
- ফলাফল PDF হিসেবে ডাউনলোড (ব্রাউজারের Print to PDF ব্যবহার করে, কোনো এক্সটার্নাল লাইব্রেরি লাগে না)
- "আমার কার্যক্রম" — অতীতের সকল পরীক্ষার ইতিহাস

**অ্যাডমিনদের জন্য**
- পরীক্ষা তৈরি/সম্পাদনা/মুছে ফেলা (সময়, নেগেটিভ মার্কিং, পাস শতাংশ কনফিগারযোগ্য)
- প্রশ্ন ম্যানেজমেন্ট (ম্যানুয়ালি একটি একটি করে, অথবা Python স্ক্রিপ্ট দিয়ে বাল্ক ইম্পোর্ট)
- সকল শিক্ষার্থীর ফলাফল একসাথে দেখা
- ড্যাশবোর্ড স্ট্যাটিসটিক্স

## সেটআপ (লোকাল — XAMPP / WAMP / Laragon)

1. পুরো ফোল্ডারটি কপি করুন `htdocs` (XAMPP) বা `www` (WAMP) এর ভেতরে, যেমন `htdocs/exam_website/`।
2. **ডাটাবেস তৈরি করুন**: phpMyAdmin খুলে `database.sql` ফাইলটি ইম্পোর্ট করুন। এতে টেবিল স্ট্রাকচার + একটি ডিফল্ট অ্যাডমিন + একটি নমুনা পরীক্ষা তৈরি হয়ে যাবে।
3. **`config/db.php`** ফাইলে আপনার MySQL ইউজারনেম/পাসওয়ার্ড বসান (ডিফল্ট XAMPP-এ সাধারণত `root` / খালি পাসওয়ার্ড কাজ করে)।
4. সাবফোল্ডারে হোস্ট করলে (যেমন `localhost/exam_website`), `config/db.php`-তে লিখুন: `define('BASE_URL', '/exam_website');`
5. ব্রাউজারে `http://localhost/exam_website/` ভিজিট করুন।

**ডিফল্ট অ্যাডমিন লগইন:** ইউজারনেম `admin`, পাসওয়ার্ড `admin123` — প্রথম লগইনের পরই বদলে ফেলুন। নতুন পাসওয়ার্ডের হ্যাশ বানাতে যেকোনো PHP ফাইলে সাময়িকভাবে চালান:
```php
echo password_hash('আপনার-নতুন-পাসওয়ার্ড', PASSWORD_DEFAULT);
```
তারপর `admins` টেবিলের `password` কলামে ফলাফলটি বসিয়ে দিন (phpMyAdmin থেকে)।

## Live হোস্টিং (cPanel / শেয়ারড হোস্টিং)

1. cPanel থেকে একটি MySQL ডাটাবেস ও ইউজার তৈরি করুন, phpMyAdmin দিয়ে `database.sql` ইম্পোর্ট করুন।
2. `config/db.php`-তে হোস্টিং থেকে পাওয়া DB হোস্ট/ইউজার/পাসওয়ার্ড/নাম বসান।
3. ফাইলগুলো `public_html/` অথবা সাবডোমেইন ফোল্ডারে আপলোড করুন (FTP বা File Manager দিয়ে)।
4. সাবফোল্ডারে থাকলে `BASE_URL` সেট করতে ভুলবেন না।

## বাল্ক প্রশ্ন ইম্পোর্ট (Python)

অনেকগুলো প্রশ্ন একসাথে যোগ করতে, এই কলামসহ একটি Excel/CSV ফাইল বানান:

| question_text | option_a | option_b | option_c | option_d | correct_option | explanation | marks |
|---|---|---|---|---|---|---|---|

তারপর নিজের কম্পিউটারে চালান:
```bash
pip install -r requirements.txt
python bulk_import.py --exam-id 1 --file questions.xlsx
```
`bulk_import.py` ফাইলের উপরের দিকে `DB_CONFIG` আপডেট করে আপনার ডাটাবেসের তথ্য বসান (হোস্ট, ইউজার, পাসওয়ার্ড)। লাইভ সার্ভারে ইম্পোর্ট করতে চাইলে সেই সার্ভারের DB হোস্ট রিমোট এক্সেস অনুমতি দিতে হবে, অথবা phpMyAdmin-এ সরাসরি CSV ইম্পোর্ট ব্যবহার করতে পারেন।

## প্রজেক্ট স্ট্রাকচার

```
exam_website/
├── database.sql              ডাটাবেস স্কিমা + নমুনা ডেটা
├── config/db.php              ডাটাবেস কানেকশন + BASE_URL কনফিগ
├── includes/                  header, footer, auth helper (session/login checks)
├── assets/                    CSS (design system) + JS (টাইমার)
├── index.php                  হোমপেজ — সকল পরীক্ষার তালিকা
├── register.php, login.php, logout.php
├── dashboard.php               শিক্ষার্থীর ড্যাশবোর্ড + কার্যক্রম
├── exam.php                    পরীক্ষা দেওয়ার পেজ (টাইমার + অটোগ্রেডিং)
├── result.php                  ফলাফল + ব্যাখ্যাসহ পর্যালোচনা + PDF
├── admin/                       অ্যাডমিন প্যানেল (লগইন, পরীক্ষা, প্রশ্ন, ফলাফল)
├── bulk_import.py               Python বাল্ক ইম্পোর্ট স্ক্রিপ্ট
└── requirements.txt
```

## নিরাপত্তা নোট

- সব পাসওয়ার্ড bcrypt দিয়ে হ্যাশ করা হয় (`password_hash`/`password_verify`)।
- সব SQL কোয়েরি PDO prepared statements দিয়ে করা, তাই SQL injection থেকে সুরক্ষিত।
- প্রোডাকশনে যাওয়ার আগে: ডিফল্ট অ্যাডমিন পাসওয়ার্ড বদলান, HTTPS চালু করুন, এবং `config/db.php`-এর ডাটাবেস পাসওয়ার্ড শক্তিশালী করুন।

## জানা সীমাবদ্ধতা / ভবিষ্যতে যোগ করা যায়

- একজন শিক্ষার্থী বর্তমানে একই পরীক্ষা যতবার ইচ্ছা দিতে পারবে — retake সীমিত করতে চাইলে `exam.php`-তে ঢোকার সময় আগের attempt চেক করার লজিক যোগ করুন।
- পাসওয়ার্ড রিসেট / ইমেইল ভেরিফিকেশন নেই।
- প্রশ্নে ছবি/ডায়াগ্রাম সাপোর্ট নেই (শুধু টেক্সট)।
